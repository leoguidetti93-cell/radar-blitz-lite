RADAR BLITZ LITE V2.0.2 — CORREÇÃO SG/G1

Regra correta:
- cada minuto possui 2 rodadas;
- 1ª rodada do minuto = SG;
- 2ª rodada do MESMO minuto = G1;
- branco na 1ª = cobertura SG;
- branco na 2ª = cobertura G1;
- após as duas rodadas sem cor indicada nem branco = LOSS.

As rodadas são ordenadas pelo timestamp antes da avaliação, evitando que a ordem retornada pela API transforme a segunda rodada em SG.
