# RADAR BLITZ V3.0.2 — Popup de branco

Correção visual pontual:
- fundo escuro (grafite/preto), texto branco e borda amarela;
- popup centralizado na tela, inclusive em celulares;
- formato mais quadrado, maior e com pedra em destaque;
- duração de 7 segundos e detecção de branco simples, duplo, triplo, sequência, espelhado e dentado preservadas.

Para atualizar o site, substitua apenas `public/style.css` no GitHub. Os demais arquivos, inclusive Worker e D1, não precisam ser alterados.
